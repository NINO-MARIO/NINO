# skill-writer
สร้างหนังสือสกิลเล่มใหม่ลงชั้นที่ถูกต้อง (หมวด › ชั้น › เล่ม) พร้อมสมุดจดคู่เล่ม
## ขั้นตอน
1. sh skills — ดูหมวด/ชั้นที่มี เลือกชั้นเดิมก่อน สร้างชั้นใหม่เมื่อไม่เข้าพวกจริงๆ
2. skill_new {cat,shelf,name,desc} หรือ sh run skills/library/make/skill-writer/scripts/new_skill.js หมวด ชั้น ชื่อ คำอธิบาย (ชื่อหมวด/ชั้น/เล่มเป็นอังกฤษ ตัวเล็ก ขีดกลาง)
3. Skill.md บรรทัดที่ 1 = # ชื่อ, บรรทัดที่ 2 = คำอธิบายสั้น (ขึ้นสารบัญเอง) ที่เหลือเป็นขั้นตอนสั้นๆ รายละเอียดยาวแยกไป docs.md
4. งานที่ผลต้องเหมือนเดิมทุกครั้ง → scripts/*.js (ctx.args ctx.fs ctx.session ctx.index ctx.log) งานที่ต้องคิด → ไม่ใส่สคริปต์
5. ตั้งชื่อหมวด/ชั้นภาษาไทย: sh write skills/หมวด/_title.md "ชื่อไทย"
