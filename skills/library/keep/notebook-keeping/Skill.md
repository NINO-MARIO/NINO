# notebook-keeping
หลังงานที่ได้บทเรียน: จดสมุดคู่เล่มทีละบทเรียน (อาการ → สาเหตุ → วิธีแก้) ให้สั้นและใช้ซ้ำได้
## ขั้นตอน
1. จบงานทุกครั้ง skill_note {name,text,kind} kind = ผิด | ได้ผล | เคล็ดลับ
2. 1 บันทึก = 1 บทเรียน: อาการ → สาเหตุ → วิธีแก้ (ไม่เกิน 3 บรรทัด)
3. ห้ามจดความลับ token รหัสผ่าน หรือเรื่องส่วนตัวผู้ใช้
4. บทเรียนเดียวกันเจอซ้ำ 3 ครั้ง → ยกขึ้นเขียนในขั้นตอนของ Skill.md เล่มนั้น (หรือทำเป็นสคริปต์) แล้วลบบันทึกซ้ำ
5. ไม่มีเล่มที่ตรงกับงาน → สร้างเล่มก่อนแล้วจด (skill-writer) อย่าทิ้งบทเรียน
