# outlaw
เกม Outlaw Immortals เล่นออฟไลน์ได้
rev: 1.3.0
## ไฟล์
- games/outlaw/: ตัวเกมเว็บ คัดมาจาก Outlaw_Immortals.zip เฉพาะส่วน assets/web (index.html, fonts, assets) ไม่รวมส่วน Android (AndroidManifest, classes.dex, res, META-INF, dexopt, ไลบรารี Kotlin)
- games/outlaw/assets/*.mjs: โมดูล ES ของเกมและชุดภาษา ตั้งชื่อ .mjs เพราะเป็นโมดูล ไม่ใช่สคริปต์ธรรมดา
- js/outlaw.js: ปุ่มบนแถบเครื่องมือ (ถัดจาก Among AI) และหน้าซ้อนเต็มจอที่ฝัง games/outlaw/index.html ในไอเฟรม ปิดด้วยปุ่มปิดหรือ Esc ตอนปิดจะว่างไอเฟรมเพื่อหยุดเกมและเสียง
- เต็มจอ (js/outlaw.js + MainActivity.kt): ปุ่มเต็มจอข้างปุ่มปิดซ่อนแถบ .ol-top ปุ่มออกโปร่งแสงมุมบนซ้ายแสดงเฉพาะตอนเต็มจอ ตอนเปิดเกมในแอป NINO ระบบจะซ่อนแถบสถานะและแถบนำทางด้วย op "immersive" และคืนค่าเมื่อปิด สลับเต็มจอไม่โหลดไอเฟรมใหม่
- ปุ่มย้อนกลับของ Android และ Esc ใช้ลำดับเดียวกันผ่าน window.ninoOutlaw.back(): ออกจากเต็มจอก่อน ถ้าไม่ได้เต็มจอก็ปิดเกม แอปไม่ปิดขณะเปิดเกม ดู DECISIONS.md (2026-11-14)
## การเล่น
- เกมทำงานเองทั้งหมดในเครื่อง ไม่ต้องมีเซิร์ฟเวอร์ของเกม
- เล่นออฟไลน์ได้แม้ไม่เคยเปิดเกมตอนออนไลน์มาก่อน: service worker เก็บไฟล์ทั้งหมดของเกมตามรายการ games/outlaw/offline-files.json ตอนแอปทำงาน (ประมาณ 25 MB บนเว็บ ใน APK เกมมาพร้อมแอปอยู่แล้ว) ทดสอบด้วย tools/test/outlaw-offline.test.js: เปิดแอปออนไลน์ รอให้เก็บครบ ตัดเน็ต แล้วเกมต้องวาดภาพได้
- ถ้าเกมยังโหลดไม่ครบ ไอเฟรมจะแสดงข้อความแจ้งผู้เล่น ไม่ปล่อยจอว่าง (js/outlaw.js)
- เกมเติม ?v=... ท้ายชื่อไฟล์ การค้นในแคชของเกมจึงไม่สนใจ query (js/service-worker.js: gameLookup)
- เซฟอยู่ใน localStorage ของแอป (จุดเดียวกับแอป) ไม่ได้ซิงก์ขึ้นคลาวด์เมื่อออฟไลน์
- เกมไม่ติดต่อโดเมนของผู้พัฒนาเลยในบิลด์ NINO (เทเลเมทรี A/B การตรวจเวลา การเปิดใช้งาน บัญชี) เวลาในเกมใช้นาฬิกาเครื่อง และตัวกันย้อนเวลา (tclock) ไม่ทำงาน ดู DECISIONS.md
## ข้อควรระวัง
- การเปลี่ยนแปลงกับตัวเกม: พาธ (GS เป็น "./", url() ใน CSS, index.html สัมพัทธ์), ชื่อโมดูล .js เป็น .mjs และการปิดการติดต่อโดเมนของผู้พัฒนา (ดู DECISIONS.md รอบ 2026-11-13 รอบ 3) ตรรกะการเล่นและการซื้อไม่ถูกแก้
- การตรวจลายเซ็นคำตอบจากเซิร์ฟเวอร์ (N$) ถูกลบแล้ว ตรวจเฉพาะ nonce; ไม่มีเซิร์ฟเวอร์ให้ตอบจึงไม่มีผลต่อการเล่น
- ไม่ได้ใส่ในแพ็ก packs/ เพราะตัวสร้างแพ็กรองรับแค่ไฟล์ชั้นเดียว ไม่รองรับโฟลเดอร์ย่อย เกมมีโฟลเดอร์ย่อยหลายชั้น ตัวเกมจึงมาพร้อมแอป ทำให้ APK ใหญ่ขึ้น ถ้าจะย้ายไปแพ็กต้องแก้ตัวสร้างแพ็กก่อน
- เกมเปิดได้เฉพาะเมื่อไฟล์ games/outlaw/index.html อยู่ครบ ถ้าขาดไฟล์ให้ตรวจโฟลเดอร์ก่อนแจ้งผู้ใช้
- games/outlaw/offline-files.json สร้างโดย tools/make-manifests.py ห้ามแก้มือ เมื่อเพิ่มหรือลบไฟล์ของเกมให้รันตัวสร้างใหม่ ไม่งั้นตรวจ check.js จะฟ้องว่าไม่ตรง
- games/outlaw/NOTICE.txt เป็นบันทึกแหล่งที่มาและสถานะ ไม่ใช่ใบอนุญาต ต้องแทนที่ด้วยเอกสารจากเจ้าของก่อนแจกจ่าย
- ดู NOW.md สำหรับรายการไฟล์และสถานะจริงของโปรเจกต์
