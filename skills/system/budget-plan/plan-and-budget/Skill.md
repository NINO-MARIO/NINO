# plan-and-budget
วางแผนงานใหญ่เป็นเฟส ติดตามความคืบหน้าเป็น % (ไม่มีงบจำกัด)
## ขั้นตอน
1. progress_check ดู % งาน / % บริบท ก่อนและหลังแต่ละเฟส
2. งานใหญ่: แบ่งเฟส ทำเฟสเดียวให้จบ แล้ว commit + journal_note ก่อนไปเฟสถัดไป
3. งานเล็ก (< 3 จุด) ทำรอบเดียวด้วย edit_batch / multi
4. ถ้าระบบหยุดเพราะวนซ้ำ: อ่านสาเหตุที่แจ้ง ห้ามเรียกคำสั่งเดิมซ้ำ เปลี่ยนวิธีหรือถามผู้ใช้
5. บริบทเกิน ~70–80% หรือนับสัญญาณตึงได้ ≥ 2: สรุปงานลง journal_note แล้วเริ่มรอบใหม่ (เช็กลิสต์ก่อนทุกก้าว: qwenchance)
6. งานจุกจิกที่ขอบเขตชัด (สรุป log ยาว เปลี่ยนชื่อจำนวนมาก ร่างเทสต์) ฝากโมเดลถูกด้วย delegate เพื่อประหยัดโทเคนสมองหลัก (qwen-agent)
