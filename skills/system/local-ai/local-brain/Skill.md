# local-brain
ทำงานเมื่อ NINO คุยผ่าน Local AI (เซิร์ฟเวอร์ในมือถือ/คอมในบ้าน) โมเดลเล็ก บริบทสั้น ต้องช่วยมันด้วยวิธีทำงาน
## ขั้นตอน
1. โหมดคุยผ่าน Local AI (ระบบเลือกให้เองเมื่อพร้อมและข้อความเป็นการคุย) = คุยล้วน (ไม่มีเครื่องมือ) · โหมดหลัก (provider local) = มีเครื่องมือ แต่เสี่ยงพังกว่า
2. ทำทีละ 1 เครื่องมือต่อรอบ ไม่วางแผนยาว · ไฟล์ใหญ่ใช้ find_text/list_functions แล้วค่อย replace_function
3. งานซ้ำให้เรียกสคริปต์ (sh run …) แทนการเขียนโค้ดเอง
4. JSON ผิดรูป → ระบบซ่อมให้ 1 ชั้น ถ้ายังพัง ตอบสั้นลง หรือคุยสั้นๆ ให้ระบบใช้โหมดคุย Local AI
5. งานเกินโมเดลเล็ก (โค้ดยาว/เหตุผลลึก) → บอกผู้ใช้ให้สลับไปใช้คลาวด์ ไม่ฝืนทำ
6. จบงานแล้ว skill_note บันทึกว่าโมเดลไหนทำอะไรได้/ไม่ได้
7. prompt.md ในโฟลเดอร์นี้คือ system prompt ของ Local AI (ผู้ใช้แก้ได้ในหอสมุด NINO แก้เองไม่ได้)
8. เชื่อมไม่ได้: อ่านคำใบ้ในข้อความผิดพลาด (บอก https/CORS/พอร์ต) · จุดสีสถานะ Local AI: เขียว=พร้อม แดง=ล้มเหลว (แตะเพื่อตรวจ) · มีตัวสำรองไปคลาวด์เมื่อมีคีย์ API
9. ผลค้นคว้าและเหตุผลการตัดสินใจ: docs.md
