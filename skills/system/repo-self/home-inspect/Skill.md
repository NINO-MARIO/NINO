# home-inspect
ตรวจสุขภาพ "บ้าน" (ไฟล์ของแอปนี้) และเปิดให้ AI ภายนอกอ่านได้อย่างเดียว
## ขั้นตอน
1. ผู้ใช้กด `>_` › ตรวจสอบเว็บบ้าน ได้รายงาน: ไฟล์ทุกไฟล์ (ขนาด/แฮช/ไวยากรณ์), SW, ไฟล์ที่แก้ในเครื่อง, ชื่อซ้ำข้ามไฟล์
2. ปุ่มคัดลอก: รายงาน · ไฟล์ทั้งหมด · ลิงก์สำหรับ AI ภายนอก (llms.txt + ai/manifest.json)
3. AI ภายนอกที่ท่องเว็บอ่าน llms.txt แล้วดึงไฟล์ตาม path ได้ แก้ไม่ได้ (โฮสต์แบบสแตติก ไม่มีช่องเขียน)
4. AI ที่สั่งรัน JS ในหน้าเว็บได้ ใช้ `ninoInspect` (list/read/report/bundle) ซึ่งเป็น object แบบ frozen อ่านอย่างเดียว
5. ถ้ารายงานมี "ปัญหา" ให้แก้ก่อนทำอย่างอื่น: ไวยากรณ์ผิด / const-let-class ซ้ำข้ามไฟล์ / ไฟล์โหลดไม่ได้
## ข้อจำกัด
- ai/manifest.json และ home.json เป็นของ ณ เวลาที่แจก ไฟล์ใหม่ที่เพิ่มทีหลังต้องอัปเดตสองไฟล์นี้
- AI ที่ควบคุมเบราว์เซอร์เต็มรูปแบบยังเรียกฟังก์ชันอื่นได้ การเขียนระบบมีด่านรหัสผ่าน (self_patch) กั้นไว้
