# github-ops
ก่อนแตะรีโปด้วย gh_*: grep/outline ก่อนอ่าน รวม op ในคำสั่งเดียว แล้ว diff → commit (กฎเต็มอยู่ใน Skill.md ที่ราก)
1. gh_grep/gh_outline ก่อน gh_read · รวมหลาย op ใน gh_edit เดียว
2. gh_diff → gh_commit {message} แล้วบอกผู้ใช้รอ ~1 นาทีแล้วรีเฟรช
3. ไฟล์ระบบต้องให้ผู้ใช้อนุมัติ · ห้ามใส่ token ลงไฟล์
