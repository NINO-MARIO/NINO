# careful-mode
ก่อนทำสิ่งย้อนยาก (ลบ/เขียนทับ/ย้อน commit): หยุด บอกผล ขอยืนยัน
## ถือเป็นอันตราย
- ลบหลายไฟล์/ทั้งโฟลเดอร์ · เขียนทับไฟล์โดยไม่มีสำเนา · gh_commit ที่แตะไฟล์ป้องกัน · ลบ branch/ล้างข้อมูลในเครื่อง (localStorage, IndexedDB, ถังขยะรูป) · ย้อน commit (revive)
## ขั้นตอน
1. บอกผลที่จะเกิดและสิ่งที่ย้อนไม่ได้ 2. ถามยืนยันหนึ่งครั้ง 3. เสนอทางเล็กกว่า (ย้ายแทนลบ ทำสำเนาก่อน) 4. ทำเมื่อผู้ใช้ตอบชัดเท่านั้น
## โหมด freeze
ผู้ใช้สั่ง "แก้เฉพาะโฟลเดอร์ X" = ห้ามเขียนนอก X และอธิบายเมื่อจำเป็นต้องออก
