# thai-text
แก้คำไทยพิมพ์ผิดและสระ/วรรณยุกต์ซ้อนจาก LLM ที่ post-process ไม่ใช่แก้ที่ prompt อย่างเดียว
## ขั้นตอน
1. sh run skills/lang/thai/thai-text/scripts/fix_thai.js ไฟล์.txt — แก้ในไฟล์โปรเจกต์
2. คำที่ต้องดูเอง (ไม่แก้อัตโนมัติเพราะเป็นคำจริงได้): คำที่เป็นคำจริงได้ — ตรวจตามบริบท
3. เจอคำผิดแบบใหม่ → จดสมุด แล้วเติมในสคริปต์ (รายการ R)
