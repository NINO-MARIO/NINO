# security-review
ก่อน commit ที่แตะคีย์/token/อินพุต/เครือข่าย: เช็กลิสต์ความปลอดภัย
## เช็กลิสต์
1. ความลับ: ไม่มี token/คีย์ API ในโค้ดหรือเอกสาร · token อยู่ localStorage เครื่องเดียวเท่านั้น · .gitignore ครอบไฟล์คีย์
2. อินพุต: ข้อความที่มาจากผู้ใช้/โมเดล/เว็บ ห้ามใส่ innerHTML ตรงๆ (ใช้ textContent หรือหุ้มค่า เหมือนการ์ด HUD)
3. เครือข่าย: ทุกคำขอผ่าน ninoGuard.fetch · ห้ามส่งความลับไปโดเมนอื่นนอกที่ผู้ใช้ตั้ง
4. ไฟล์ป้องกัน: gh_commit ที่แตะต้อง confirm:true และให้ผู้ใช้กดอนุมัติ ห้ามอ้อม
5. ผลลัพธ์: log และข้อความ error ห้ามพิมพ์ค่าความลับ
## รายงาน
ผ่าน/ไม่ผ่านรายข้อ พร้อมไฟล์:บรรทัด ข้อไหนไม่ได้ตรวจให้บอกตรงๆ
