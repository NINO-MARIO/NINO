# silent-failure-hunter
ก่อน commit หรือบั๊กอธิบายไม่ได้: ไล่หาจุดที่ล้มเงียบ (catch ว่าง, ค่าเริ่มต้นกลบ error)
## ขั้นตอน
1. gh_grep หา catch ว่าง, .catch(()=>{}), || [] / || {} ที่กลบความล้มเหลว, return ใน catch โดยไม่ log
2. fetch ทุกจุดต้องผ่าน ninoGuard.fetch (timeout/retry/ตัดวงจร) ถ้าเรียกตรงให้ถือเป็นข้อค้นพบ
3. แต่ละจุดตอบ 3 ข้อ: ผู้ใช้จะเห็นอะไรเมื่อล้ม · log พอให้ตามรอยไหม · มีทางไปต่อไหม
4. รายงานเรียงความรุนแรง: ไฟล์:บรรทัด · สิ่งที่ถูกกลบ · แก้เล็กที่สุด
## กฎ
- แก้ที่ชั้นที่ล้ม ห้ามเพิ่ม catch ชั้นนอกเพื่อกลบ · ข้อความ error ถึงผู้ใช้ต้องเป็นไทยและบอกทางไปต่อ
