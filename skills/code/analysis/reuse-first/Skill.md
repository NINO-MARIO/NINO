# reuse-first
ก่อนเขียนฟังก์ชัน/ไฟล์ใหม่: หาของเดิมก่อน แล้วเลือก ใช้/ต่อยอด/สร้าง
## ขั้นตอน
1. เขียนสิ่งที่ต้องการหนึ่งประโยค
2. หาในบ้าน: NOW.md (แผนที่ไฟล์) · gh_grep · sh run skills/code/analysis/code-analysis/scripts/outline.js
3. หานอกบ้านเมื่อจำเป็น: web_search ไลบรารีเล็กที่ไม่ต้องมีขั้นตอนบิลด์ (แอปเป็นสคริปต์ธรรมดา ห้ามพึ่งแพ็กเกจหนัก)
4. ตัดสิน: ตรงเป๊ะ=ใช้เลย · ใกล้เคียง=ห่อบางๆ · ไม่มี=สร้างเล็กที่สุด
## กฎ
- สร้างใหม่ต้องบอกว่าหาที่ไหนแล้วไม่เจอ · เพิ่มไฟล์ใหม่ต้องเพิ่มบทบาทใน tools/file-roles.json
