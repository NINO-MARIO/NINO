# fact-first
ก่อนแก้ไฟล์ครั้งแรก: เก็บข้อเท็จจริง (ใครอ้างถึง) ก่อนแก้ ไม่เดา
## ก่อนแก้ไฟล์ใดๆ ตอบให้ได้ 4 ข้อ
1. ใคร/ไฟล์ไหนเรียกหรืออ้างถึงไฟล์นี้ (gh_grep ชื่อฟังก์ชัน/ชื่อไฟล์)
2. ฟังก์ชันสาธารณะไหนได้รับผลกระทบ
3. ถ้าไฟล์อ่าน/เขียนข้อมูล รูปแบบข้อมูลจริงเป็นอย่างไร (ชื่อช่อง ตัวอย่างสมมติ ห้ามใช้ข้อมูลผู้ใช้จริง)
4. คำสั่งล่าสุดของผู้ใช้ตรงตัว (ยกมาทั้งประโยค) แล้วตรวจว่าการแก้ไม่เกินขอบเขตนั้น
## กฎ
- ตอบไม่ได้ = ยังไม่แก้ ไปอ่านก่อน · ไฟล์ป้องกัน/ล็อกใน NOW.md ต้องรอผู้ใช้สั่งชัด
- ใช้คู่กับ fast-edit (ตอนลงมือ) และ scrutinize (ก่อน commit)
