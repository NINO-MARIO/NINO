# anti-loop
เมื่อระบบหยุดเพราะ "วนซ้ำ" ต้องทำอย่างไร (ตัวกันลูปอยู่ที่ js/loop-guard.js)
## ขั้นตอน
1. คำใบ้ "..." ในผลลัพธ์เครื่องมือ = ระบบเตือนเบา ๆ ผู้ใช้ไม่เห็น ให้เปลี่ยนวิธีทันที ไม่ต้องรอให้ถูกหยุด
2. ห้ามเรียกคำสั่งเดิมด้วยพารามิเตอร์เดิมซ้ำ (ครั้งที่ 2 และ 4 ระบบเตือน ครั้งที่ 6 ถึงหยุดถามผู้ใช้)
3. เปลี่ยนวิธี: ผิดชื่อ → outline แล้วใช้ชื่อจริง · find ไม่เจอ → read_range ดูข้อความจริง · อ่านรีโปแล้ว → gh_outline เฉพาะไฟล์ แล้ว gh_edit · แก้วน → ถามผู้ใช้ว่าต้องการอะไร
4. อ่านไฟล์ "ต่างกัน" ไม่ใช่การวน · gh_edit/gh_create ที่สำเร็จนับเป็นความคืบหน้า
5. หยุดจริงเมื่อ: เรียกเดิมซ้ำ 6 ครั้ง / ล้มเหลวติดกัน 8 ครั้ง / อ่านซ้ำไม่คืบหน้า 25 ครั้ง / ไฟล์กลับสถานะเดิม 4 ครั้ง (ปิดได้ด้วย ninoLoopGuard.cfg.hardStop=false)
6. จดสมุด: คำสั่งที่เคยทำให้วน + วิธีที่แก้ได้
7. ระบบกันลูปคือเพดานสุดท้าย ไม่ใช่เป้า — วินัยก่อนถึงเพดาน (ลองไม่เกิน 3 ครั้ง ห้ามแก้มืด ส่งต่อเมื่อบริบทตึง) อยู่ที่ system/budget-plan/qwenchance
