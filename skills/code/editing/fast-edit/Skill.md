# fast-edit
แก้โค้ดให้เร็วและเสี่ยงน้อย ด้วยทางลัดที่รวมหลายจุดในคำสั่งเดียว
## ขั้นตอน
1. ดู "แผนที่โค้ด" ใน prompt หรือสั่ง outline เพื่อรู้ชื่อฟังก์ชัน+เลขบรรทัด (ไม่ต้องอ่านทั้งไฟล์)
2. แก้ด้วย edit_batch {path,edits:[...]} — แบบที่ใช้: {find,replace,near?} · {lines:[เริ่ม,จบ],text} · {insert_after|insert_before:"ข้อความ"|เลขบรรทัด,text} · {delete:"ข้อความ"} · {append}
3. เลขบรรทัดอ้างอิงไฟล์ก่อนแก้ทั้งหมด (ไม่ต้องคำนวณเลื่อน) ตรวจไวยากรณ์ให้ ถ้าพังไม่บันทึกและบอกสาเหตุ
4. find ซ้ำหลายจุด: ใส่ near:<เลขบรรทัด> หรือ all:true ระบบบอกเลขบรรทัดที่ซ้ำให้
5. หลายเครื่องมือต่อกัน: multi {calls:[{name,args}...]} (สูงสุด 8) หยุดเองเมื่อมีตัวพลาด
6. พลาดแล้วย้อนด้วย undo {path} · replace_function ผิดชื่อ ระบบบอกชื่อจริงและชื่อใกล้เคียงให้
