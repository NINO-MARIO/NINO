# tdd-loop
ทำฟีเจอร์/แก้บั๊กที่ทดสอบได้: เขียนเทสต์ล้มก่อน แล้วแก้ให้ผ่าน
## วงจร
1. แดง: เขียนเทสต์ใน tools/test/ ที่จับพฤติกรรมหรือบั๊ก รันแล้วต้องล้มด้วยเหตุผลที่ถูก (จดข้อความที่ล้ม)
2. เขียว: แก้โค้ดน้อยที่สุดให้ผ่าน
3. เก็บกวาด: จัดโค้ดโดยเทสต์ยังเขียว
4. รัน bash tools/verify-all.sh ทั้งชุด
## กฎ
- ครอบกรณีขอบ: ว่าง, null, ข้อความไทย, ข้อความยาวมาก, ออฟไลน์/เครือข่ายล้ม
- ห้ามแก้ค่าที่คาดหวังในเทสต์ล็อกเพื่อให้ผ่าน (ดู HANDOFF) · เทสต์ที่ mock จนซ่อนบั๊กไม่นับ
- ถ้าทดสอบไม่ได้ในที่ทำงานนี้ ให้บอกตรงๆ ว่าต้องทดสอบบนเครื่องจริง
